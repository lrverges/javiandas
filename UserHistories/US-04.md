### 1. User Story
**Como** Usuario (Particular o Empleado)
**Quiero** gestionar mis direcciones de entrega y elegir una predeterminada
**Para** agilizar el proceso de envío y recibir las viandas en el lugar correcto.

### 2. Descripción de la Funcionalidad (Flow)
#### Flujo de Gestión de Direcciones:
1. El usuario accede a la sección "Mis Direcciones".
2. Ve la lista de sus direcciones guardadas.
3. Puede agregar una nueva completando: Calle, Altura, Localidad y Referencia ("Casa", "Oficina").
4. Si el usuario es corporativo, el frontend/backend valida la regla `permitir_direcciones_extras` de la empresa (configurada en **US-02**). Si es `false`, se bloquea la creación de nuevas direcciones y solo puede usar la de la empresa.
5. El usuario puede marcar una dirección como "Predeterminada" mediante un radio button o botón de estrella.
6. Al marcar una como predeterminada, el backend actualiza automáticamente, quitándole esa marca a cualquier otra. La dirección predeterminada es clave para armar la Hoja de Ruta (**US-13**).

### 3. Lista Completa de Campos
*   `street`: String, requerido.
*   `number`: String, requerido.
*   `locality`: String, requerido.
*   `reference`: String, requerido.
*   `isDefault`: Boolean.

### 4. Estructura de Endpoints y URLs

#### 4.1 Obtener direcciones: `GET /api/users/me/addresses`
- **Success Response**:
```json
{
  "success": true,
  "data": [
    { "id": 1, "street": "Av Belgrano", "number": "100", "locality": "Lules", "reference": "Casa", "isDefault": true }
  ]
}
```

#### 4.2 Agregar dirección: `POST /api/users/me/addresses`
- **Request Body**:
```json
{
  "street": "San Martin", "number": "450", "locality": "Lules", "reference": "Trabajo 2"
}
```

#### 4.3 Marcar como predeterminada: `PUT /api/users/me/addresses/:addressId/default`
- **Success Response**:
```json
{
  "success": true,
  "message": "Dirección actualizada correctamente."
}
```
