### 1. User Story
**Como** Administrador de Javiandas
**Quiero** contar con un panel de planificación visual e interactivo
**Para** asignar y estructurar la oferta comercial de platos por día y tipo de cliente de forma ágil.

### 2. Descripción de la Funcionalidad (Flow)
1. El Administrador selecciona la semana a planificar y el "Tipo de Menú" (Corporativo, Corporativo Premium, Particulares).
2. Se muestra una grilla de 7 columnas (Lunes a Domingo).
3. Si un día es feriado (basado en la **US-06**), la columna aparece resaltada/bloqueada. Si no está marcado como feriado, el admin puede hacerlo "in-place".
4. En cada columna, el admin tiene un componente `<select>` asíncrono con buscador.
5. Al buscar y seleccionar un plato del Catálogo (**US-05**), este se fija para ese día, y automáticamente aparece debajo un nuevo `<select>` vacío, permitiendo cargar opciones ilimitadas por día.
6. Si el plato que busca no existe, hay un botón "Crear Plato" que abre un modal, crea el plato en el catálogo y lo auto-asigna a ese día sin perder el contexto.
7. Al finalizar, hace clic en "Guardar Semana".

### 3. Lista Completa de Campos
*   `week`: String (YYYY-WW).
*   `menuType`: Enum.
*   `dailyMenus`: Array de objetos con `date` y arreglo de `dishIds`.

### 4. Estructura de Endpoints y URLs

#### 4.1 Guardar Planificación Semanal: `PUT /api/admin/menus/weekly`
- **Request Body**:
```json
{
  "week": "2026-W20",
  "menuType": "Corporativo",
  "dailyMenus": [
    {
      "date": "2026-05-18",
      "dishIds": [1, 5, 8]
    },
    {
      "date": "2026-05-19",
      "dishIds": [2, 7]
    }
  ]
}
```
