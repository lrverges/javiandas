### 1. User Story
**Como** Administrador de Javiandas
**Quiero** contar con una sección interna de alertas/historial en la aplicación
**Para** enterarme en tiempo real de las modificaciones logísticas realizadas por las empresas clientes.

### 2. Descripción de la Funcionalidad (Flow)
1. El Administrador ingresa al "Panel de Alertas" o visualiza una campanita de notificaciones.
2. El panel lista de forma cronológica descendente todos los eventos de sistema generados (particularmente los disparados por la **US-10** cuando un empleado es deshabilitado).
3. Cada alerta muestra fecha, hora, empresa, y detalle de la resolución.
4. El admin puede marcar alertas como "Leídas".

### 4. Estructura de Endpoints y URLs

#### 4.1 Obtener alertas: `GET /api/admin/alerts`
- **Success Response**:
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "createdAt": "2026-05-18T10:00:00Z",
      "company": "ACME S.A.",
      "message": "Empresa ACME deshabilitó a Juan Pérez. Pedidos de martes cancelados; jueves mantenidos.",
      "isRead": false
    }
  ]
}
```

#### 4.2 Marcar como leída: `PUT /api/admin/alerts/:id/read`
- **Success Response**:
```json
{ "success": true }
```
