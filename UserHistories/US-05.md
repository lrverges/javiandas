### 1. User Story
**Como** Administrador de Javiandas
**Quiero** dar de alta, editar o eliminar platos en un catálogo general
**Para** mantener un inventario de opciones reutilizables para los menús semanales.

### 2. Descripción de la Funcionalidad (Flow)
1. El Administrador ingresa a la vista "Catálogo de Platos".
2. Puede visualizar una grilla con todos los platos dados de alta.
3. Puede agregar un nuevo plato completando: Nombre, Descripción, y Tipo (Normal / Premium).
4. Puede editar los detalles de un plato existente.
5. Puede "eliminar" (Soft Delete o desactivar) un plato si ya no se cocinará.

### 3. Lista Completa de Campos
*   `name`: String, requerido.
*   `description`: String.
*   `type`: Enum (`Normal`, `Premium`), requerido.
*   `isActive`: Boolean.

### 4. Estructura de Endpoints y URLs

#### 4.1 Obtener Catálogo: `GET /api/admin/dishes`
- **Success Response**:
```json
{
  "success": true,
  "data": [
    { "id": 1, "name": "Milanesa de pollo", "description": "Con puré mixto", "type": "Normal", "isActive": true }
  ]
}
```

#### 4.2 Crear Plato: `POST /api/admin/dishes`
- **Request Body**:
```json
{
  "name": "Sorrentinos de Jamón y Queso",
  "description": "Con salsa filetto",
  "type": "Premium"
}
```
