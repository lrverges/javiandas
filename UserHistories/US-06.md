### 1. User Story
**Como** Administrador de Javiandas
**Quiero** definir los horarios límite de pedidos y el calendario de feriados
**Para** automatizar el bloqueo de solicitudes y modificaciones por parte de los clientes.

### 2. Descripción de la Funcionalidad (Flow)
1. El Administrador accede a "Configuración de Reglas".
2. **Regla General**: Define a qué hora exacta del día se corta la posibilidad de hacer pedidos para el día siguiente (Ej: 20:00 hs).
3. **Regla de Lunes**: Como el fin de semana no hay administración normal, se configura a qué hora del Viernes o Sábado se cierran los pedidos del Lunes siguiente.
4. **Feriados**: Permite agregar fechas a un calendario de feriados, asociándoles un día previo laboral de cierre y su hora de corte respectiva. Estas reglas son el núcleo para la **US-09** (Bloqueo automatizado).

### 3. Lista Completa de Campos
*   `generalCutoffTime`: String (HH:mm).
*   `mondayCutoffDay`: Enum (Friday, Saturday).
*   `mondayCutoffTime`: String (HH:mm).
*   `holidays`: Array de { `date`: YYYY-MM-DD, `cutoffDate`: YYYY-MM-DD, `cutoffTime`: HH:mm }.

### 4. Estructura de Endpoints y URLs

#### 4.1 Obtener reglas: `GET /api/admin/settings/rules`
- **Success Response**:
```json
{
  "success": true,
  "data": {
    "generalCutoffTime": "20:00",
    "mondayCutoffDay": "Friday",
    "mondayCutoffTime": "15:00"
  }
}
```

#### 4.2 Guardar reglas: `PUT /api/admin/settings/rules`
- **Request Body**:
```json
{
  "generalCutoffTime": "20:00",
  "mondayCutoffDay": "Friday",
  "mondayCutoffTime": "15:00"
}
```
