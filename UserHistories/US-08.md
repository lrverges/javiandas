### 1. User Story
**Como** Usuario (Particular o Empleado)
**Quiero** ver el calendario semanal con las opciones disponibles según mi beneficio
**Para** elegir mi menú diario o modificar mis selecciones previas.

### 2. Descripción de la Funcionalidad (Flow)
1. El usuario accede a la sección "Mi Menú".
2. El sistema determina el "Tipo de Beneficio" del usuario (Particular, Corp, Corp Premium).
3. El frontend solicita al backend el menú disponible de la semana actual y la próxima.
4. Se muestra un carrusel o calendario. Los días pasados o cerrados por horario (**US-09**) aparecen deshabilitados ("Cerrado").
5. Para los días abiertos, el usuario ve los platos asignados por el Admin en la planificación (**US-07**).
6. El usuario selecciona un plato. Opcionalmente puede tildar "Entrega Prioritaria" si lo desea.
7. Guarda su selección. El backend registra el Pedido (`Order`).

### 3. Lista Completa de Campos
*   `date`: YYYY-MM-DD.
*   `dishId`: Integer.
*   `priorityDelivery`: Boolean.

### 4. Estructura de Endpoints y URLs

#### 4.1 Obtener Menú del Usuario: `GET /api/users/me/available-menus?week=2026-W20`
- **Success Response**:
```json
{
  "success": true,
  "data": [
    {
      "date": "2026-05-18",
      "status": "OPEN",
      "dishes": [{ "id": 1, "name": "Pollo" }]
    }
  ]
}
```

#### 4.2 Confirmar Pedido: `POST /api/users/me/orders`
- **Request Body**:
```json
{
  "date": "2026-05-18",
  "dishId": 1,
  "priorityDelivery": true
}
```
